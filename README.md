## 🔄 2. Shift Register

A 4-bit Shift Register implemented using Verilog HDL.

### Features

* Serial Data Input
* 4-bit Data Output
* Clock-Based Operation
* Reset Functionality

The input data is shifted through the register on every positive edge of the clock.

📁 **Project includes:**

* RTL Design
* Testbench
* Simulation Waveform

---

## 🔢 3. 4-bit Up/Down Counter

A synchronous 4-bit Up/Down Counter implemented using Verilog HDL.

### Features

* Up Counting Mode
* Down Counting Mode
* Reset Functionality
* Clock-Based Operation

### Control Logic

| `up_down` | Operation        |
| --------- | ---------------- |
| 1         | Up Counting ⬆️   |
| 0         | Down Counting ⬇️ |

📁 **Project includes:**

* RTL Design
* Testbench
* Simulation Waveform
